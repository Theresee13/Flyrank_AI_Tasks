# FlyRank Engineering Portfolio

A collection of backend, API, Docker, automation, and AI projects built during the FlyRank internship track. Each folder is intentionally self-contained so it can be run, tested, and reviewed independently.

## At a glance

- **Backend APIs:** FastAPI and Express services with validation, persistence, authentication, and background work.
- **Delivery tooling:** Docker Compose setups, database examples, API collections, and test suites.
- **AI systems:** workflow automation, retrieval-assisted planning, risk assessment, and visual decision flows.
- **Evidence:** project READMEs, screenshots, and verification notes are kept beside the implementation they describe.

## Repository notes

Environment files are represented by `.env.example` templates; local secrets must remain in ignored `.env` or `.env.local` files. Generated databases, build output, logs, and virtual environments are excluded through the root `.gitignore`.

For the current implementation map and outstanding evidence, see [ASSIGNMENT_COMPLIANCE.md](./ASSIGNMENT_COMPLIANCE.md). For work that still needs a live account, portal, or local runtime, see [SUBMISSION_WORKFLOW.md](./SUBMISSION_WORKFLOW.md).
